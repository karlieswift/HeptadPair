# Data availability and redistribution boundary

This compact GitHub release intentionally does **not** redistribute the complete raw third-party datasets or the complete historical training repository.

Included here are:

- the frozen base-manuscript source-data workbook plus the v8.9 Phase81/Phase82 revision workbook and CSV tables;
- frozen Phase81/Phase82 result tables and gates;
- modeled Phase82 coordinate outputs needed to audit the structural illustration;
- exact analysis/revision scripts used for Phase81 and Phase82;
- dataset/feature/structure contracts and manuscript/SI sources.

Large raw public datasets should be obtained from the repositories cited in the manuscript. The release preserves the distinction between experimental observations, directed feature-construction rows, frozen model outputs and modeled structural coordinates.
