# Release checklist

Scientific/reviewer package:

- [x] final v8.9 manuscript and SI included
- [x] main and supplementary figures included
- [x] Phase81 full-factorial results and exact scripts included
- [x] Phase82 case-selection/PDB-screen/modeling/matched-control results and scripts included
- [x] public-safe source-data workbook + CSV exports included
- [x] local developer paths removed/replaced with repository-relative placeholders
- [x] SHA256 manifest and verification scripts included
- [x] reviewer-ready release gate passes

Permanent public release metadata:

- [ ] choose final software/content license
- [ ] add final GitHub repository URL
- [ ] add archival DOI if/when deposited
- [ ] finalize funding statement
- [ ] finalize detailed CRediT roles
- [ ] confirm final competing-interest wording

`PUBLIC_RELEASE_GATE.json` intentionally keeps `public_release_ready=false` until those author-controlled metadata are completed.
